# RDK X5 芒果疏果视觉程序

程序按比赛流程运行：等待电控发送 `S/s`，顶部相机完成车体对中，随后侧相机判断四个固定位置中哪些是绿色芒果，最后等待下一棵树的 `S/s`。

## 已确认的板端设备

- RDK X5：`192.168.127.10`
- 顶部相机：`5MP USB Camera`，使用唯一的 `/dev/v4l/by-id/...P030D03...` 路径
- 侧边相机：`1080P USB Camera`，使用唯一的 `/dev/v4l/by-id/...P030102...` 路径
- 两台相机：`1280x720 MJPG 30 FPS`
- 40Pin UART1：Pin 8 TX、Pin 10 RX、设备 `/dev/ttyS1`

两台相机型号不同且都有唯一设备路径，换 USB 插口不会认反。当前默认 5MP 相机放顶部、1080P 相机放侧边；若机械安装需要反过来，交换 `config.json` 中 `top.device` 与 `side.device`。

## 接线

RDK X5 与电控必须交叉连接并共地：

| RDK X5 | 电控 |
|---|---|
| Pin 8 UART1_TXD | RX |
| Pin 10 UART1_RXD | TX |
| 任意 GND | GND |

UART 是 `3.3 V TTL`，不能接 RS-232 电平，也不要向信号脚输入 5 V。通信参数固定为 `115200, 8N1`，无流控。

## 串口协议

每条视觉回包以 `\n` 结束；电控触发可以只发一个字节，不要求换行。

| 方向 | 示例 | 含义 |
|---|---|---|
| 电控 -> 视觉 | `S` 或 `s` | 到达一棵新树，开始/重新开始完整流程 |
| 视觉 -> 电控 | `B,1` | 已接收触发，序号 1 开始 |
| 视觉 -> 电控 | `A,1,+23,-8` | 树中心相对画面参考中心：右 23 px、上 8 px |
| 视觉 -> 电控 | `T,1,+32.5` | 树在地面 XY 平面内相对车体 X 轴的朝向角，单位为度 |
| 视觉 -> 电控 | `C,1` | 连续 5 帧进入允许误差，且 `T` 已发送；这是顶部阶段最后的放行信号 |
| 视觉 -> 电控 | `G,1,L1,R2` | 只有 L1、R2 检测为绿色芒果 |
| 视觉 -> 电控 | `G,1,NONE` | 四个位置都没有绿色芒果 |
| 视觉 -> 电控 | `E,1,TREE_NOT_FOUND` | 当前没有可靠检测到树，每秒最多一次 |

`dx > 0` 表示树在画面中心右侧，`dy > 0` 表示树在画面中心下方。电控第一次联调必须低速点动，确认车体运动方向与误差减小方向一致。

`T` 消息的角度范围是 `[-90°, 90°)`：以车体 X 轴正方向为 0°，按图像坐标换算后逆时针为正。它表示树杈/树冠在水平 XY 平面内的旋转角，不是树杈在竖直方向的仰角。若电控需要另一种正负方向，只需在接收端取负号或做一次角度偏置。电控应把 `C` 当作顶部流程的最后放行信号，不要只收到 `T` 就提前进入下一步。

位置编号规定：`L1=左侧较高/外侧`，`L2=左侧较低/内侧`，`R1=右侧较高/外侧`，`R2=右侧较低/内侧`。

## 运行

```bash
cd ~/mango_vision
chmod +x run.sh
./run.sh
```

程序启动后保持等待，电控每到一棵树发一次 `S`。运行期间再次收到 `S/s` 会立即放弃上一轮并从顶部对中重新开始。

运行后，在同一局域网的电脑浏览器打开：

```text
http://192.168.127.10:8080
```

等待 `S/s` 时网页显示顶部相机；进入侧视识别后自动显示侧边相机。网页画面包含顶部中心偏差或侧边四个位置框。关闭网页不会停止视觉程序。若不需要预览，可用 `./run.sh --no-preview`。

不接电控的相机流程测试：

```bash
./run.sh --no-serial --start-now --once
```

拍摄两台相机的原图和标注图：

```bash
python3 tools/camera_check.py
```

结果保存在 `camera_check/`，正常比赛流程的关键帧保存在 `debug/`。

## 安装相机后必须调整

当前代码和协议可以直接运行，但相机尚未装车，下面三项必须用真实比赛树调好：

1. `top_detector.reference_offset_px`：夹爪真正对准树时，树中心相对画面中心的固定偏置。
2. `side_detector.positions`：L1、L2、R1、R2 四个矩形框，数值是画面宽高的 0~1 比例。
3. `top_detector.orientation_offset_deg`：相机画面横轴与车体 X 轴的安装偏角。
4. 两组 `green_hsv_lower/upper`：在固定曝光和固定白平衡后，根据现场灯光调整绿色范围。

如果装车后画面上下颠倒，把对应相机的 `rotate` 改成 `180`；如果左右镜像，把 `flip_horizontal` 改成 `true`。这两个选项只改变图像方向，不改变串口协议。

默认顶部允许误差为 `15 px`，连续 `5` 帧满足才进入侧视阶段。侧视会观察 `15` 帧，某位置至少 `9` 帧检测到绿色才会上报，避免单帧反光误判。
