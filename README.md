# 标定与检测流程说明

> 给非视觉方向的人看的一页说明。核心一句话：**我们不建数学模型，我们拍图量尺寸、查表**。
> 因为相机近大远小 + 广角畸变，同一颗果在画面不同位置、不同树倾斜角下成像大小能差 3～4 倍，
> 公式算不准；而拍 14 组图半小时能拍完，量出来的数自带验证。

---

## 1. 为什么必须实测，不能算

- **近大远小**：同样 30mm 的果，离相机 20cm 和 35cm，成像面积差 **3 倍多**。
  我们实测同一棵树同一帧里，两处已知尺寸算出的尺度比就有 **1.39**；四个挂点在画面里的果径实测 **44～84px**。
- **广角畸变**：画面边缘 1 个像素代表的毫米数比中心小，果越靠边越"瘦"。
  我们这台侧视相机的水平视场约 **99°**，边缘畸变不可忽略。
- **倾斜让每个点位的深度都不一样**：树绕竖轴转 0～30°，外侧挂点会往相机方向靠/离，
  同一颗果在自己的点位上就会变大小（实测放大倍数在 1.0～1.9 之间）。
- 用公式解决要：相机内参标定 + 畸变模型 + 那个瞬间的深度 → 赛前做不完，而且**没人能验证它错没错**。
- 实测解决：拿尺子和果拍照，量出来就是对的，错了肉眼就能看出来。

---

## 2. 准备阶段要拍什么

前提：**相机装车、树装车、全部固定死**。相机一旦动过，整张表作废，必须重拍。

树的倾斜角是唯一变量，规则允许 ±30°，我们按 **5° 一档、共 7 档** 拍：

| 档位 | 0° | 5° | 10° | 15° | 20° | 25° | 30° |
|---|---|---|---|---|---|---|---|

每一档拍 **两组**，每组至少 **3 帧**（防手抖/防对焦误差）：

- **A 组 · 四点全挂果**：四个挂点全挂**奶黄果**。
  → 用来量每个点位上果的**外接矩形**，取所有帧里**最大**的那一组。
- **B 组 · 四点全空**：四个挂点都不挂果（磁铁座、粗枝端还在）。
  → 用来量"没有果时这里是什么样"的本底，这是阈值能不能站得住的关键。

额外要求：

1. 每个点位的果**转两次**：一次转到画面里最"胖"，一次最"瘦"（果是椭球，自转就变宽窄）。
2. 存**原始帧**（预览里按 `s`），PNG，**不要截图、不要微信传图**。截图被窗口缩放和 JPEG 压缩过，量出来的尺寸不可信。
3. 背景尽量暗、不要有黄色/奶白色杂物（会进同一套颜色判据）。
4. 文件名带档位（`yaw10_a_1.png` 这种），否则 14 组图分不清。

**为什么用黄果标定、绿果用**：黄果和树不同色，能干净分割出来；而"某档某点位的果在画面哪儿、多大"是**纯几何量，跟颜色无关**。所以标定阶段挂黄果，运行时判绿果。

## 3. 从这些图里量出什么

每一档、每个点位，产出 4 个数：

| 量 | 取法 | 为什么这么取 |
|---|---|---|
| 中心坐标 `(x, y)` | 该档所有帧的果心平均 | 后面要在这一带找果 |
| 外接矩形 `w × h` | 取**最大**情况 | 框是"容器"，怎么转都必须框得住；框小了果露一半，面积占比变低 → 漏检 |
| 果径 `R_core` | 最大内接圆半径（不是 `√(面积/π)`） | 果和背景/枝干粘连只会把外框撑大，不会把内接圆撑大 |
| 面积占比 | 果身像素 ÷ 矩形面积 | 判"这里有果"用的门槛 |

**阈值一定按"最小情况"定**：最瘦的角度、最远的点位，那时果身占矩形比例的**最低值**，就是门限的下界；
再拿 B 组（全空）的本底量作为上界，门限落在两者之间。

一句话记法：**框取最大（宁大勿小），阈值取最小（宁低勿高）。**

## 4. 运行时怎么用这张表

```
① 俯视相机      → 算出树的倾斜角 ψ（两枝端连线的方向角，一条线的角度，不需要标定）
                 → 同时算车与树的居中偏差，发给电控对中
② 查表 + 插值   → ψ 落在哪两档之间，就按比例插值，得到这一档四个点位的矩形位置与大小
③ 侧视相机      → 只在插值出来的矩形里数"果身像素占比"
                 → 超过阈值 = 这个点位有果；连续 N 帧都比较高才确认，一帧明显低就否决
```

**离散的 7 档为什么够用**：角度是连续的，但点位在画面里的移动，5° 之内近似线性，
两档之间按角度线性插值就能覆盖。一个档位的间隔内，点位的位移远小于矩形的尺寸，所以插值误差被矩形吃掉了。

**例外要老实标**：实测发现某个点位在某一档会被树干挡住（内挂点靠树干，很容易挡），
就在表里把这个"档 × 点位"标成 **不可观测** —— 那时宁可报"这里没有"，也不猜。猜错的代价是
一颗果按黄果处理（−20 分，抵掉两颗绿果），而漏一颗只是少 10 分。

---

## 5. 各方向要保证的事

- **机械**：相机相对车体**绝对固定**；侧视相机到树干轴的距离与高度要写进图纸（我们实测现在约 **22.5cm**、水平视场约 **99°**，覆盖 yaw 0° 够用，±30° 时靠内那侧会贴边，需要留余量）。
- **电控**：对中完成信号、四个点位的动作时序；我们只报"这个点位有果/没有果"，不给毫米坐标。
- **视觉**（我们）：7 档标定表 + 阈值 + 俯视角度和居中偏差。
